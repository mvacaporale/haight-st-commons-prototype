HSt.C

Haight St. Commons — Prototype

Design mockups for the planned self-serve platform where co-op houses manage their own listings and seekers browse & apply. Dummy data (“Fernwood”); no backend.

How to view: open any file below directly in a browser, or run a static server from the repo root (python3 -m http.server) and visit localhost:8000. Everything is a single self-contained HTML file — edit the markup/CSS inline.
